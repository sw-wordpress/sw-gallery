# SW Gallery documentation

SW Gallery lets WordPress editors create galleries from Media Library images, arrange them and embed them in posts or pages. Gallery operations change image references, not the original files. Galleries have no public URL of their own.

- [Getting started](getting-started.md): requirements, installation and your first published gallery.
- [Manage galleries and images](galleries.md): create, duplicate, edit, reorder, preview and remove galleries; use Media Overview.
- [Layouts and presentation](layouts.md): choose a registered layout and adjust responsive settings, image crops and hover texts.
- [Embed a gallery](embedding.md): use the SW Gallery block or shortcode, page through images and open the lightbox.
- [Settings, access and privacy](settings-and-access.md): site defaults, permissions, visibility and data retention.
- [Troubleshooting](troubleshooting.md): blank galleries, failed uploads, conflicts, expired sessions and system diagnostics.
- [Changelog](Changelog.md): unreleased changes and recorded version history.

The instructions follow the current repository, including changes listed as **Unreleased**. An older installed release may not include every control. English labels are used here; the administration interface also supports German.

Cloud-source connectors and gallery import/export are not implemented. Developer integrations are covered in the [technical documentation](https://github.com/sw-wordpress/sw-gallery/blob/main/docs/extending.md).
